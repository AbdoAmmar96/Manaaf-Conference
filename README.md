# نظام حفل افتتاح مدينة منافع الصناعية المتكاملة

نظام إدارة متكامل لحفل الافتتاح: تسجيل الضيوف، بطاقات QR، الدخول (Check-in) بالكاميرا،
استقبال الرسائل والاستفسارات، والتقاط الاهتمامات (Leads) من مناطق العرض.

**التقنيات:** Laravel 13 · PHP 8.3 · MySQL (أو SQLite للتطوير المحلي) · واجهة عربية RTL

---

## المزايا

| الوحدة | الوصف |
|---|---|
| **الواجهة العامة** | صفحة الحفل والعد التنازلي، التسجيل الذاتي، تأكيد الحضور (RSVP)، صفحة المستثمرين، نموذج التواصل |
| **بطاقات QR** | لكل ضيف رمز QR فريد على `‎/my-qr/{token}` مع صورة قابلة للتحميل والإرسال |
| **الضيوف** | إضافة من الاستقبال أو تسجيل ذاتي، تصنيف الضيوف، وحالات الحضور |
| **Check-in** | ماسح QR بالكاميرا + بحث يدوي بالاسم/الجوال، مع منع تكرار الدخول |
| **الرسائل** | استقبال وتصنيف الرسائل (عادية / مستثمرين) مع سجل متابعة الحالة والملاحظات الداخلية |
| **اهتمامات العملاء** | تسجيل الاهتمام والدرجة (ساخن/متوسط/بارد) والملاحظات والموظف المسؤول وموعد المتابعة — من فريق المبيعات أو من رمز QR الخاص بكل منطقة |
| **المناطق** | إدارة مناطق العرض مع رمز QR مطبوع لكل ماكيت |
| **التقارير** | تقارير تجميعية وتصدير الضيوف والاهتمامات والرسائل إلى Excel/CSV |
| **الصلاحيات** | ثلاثة أدوار: مدير النظام، استقبال، مبيعات — راجع [docs/الصلاحيات.md](docs/الصلاحيات.md) |

## التشغيل المحلي

```bash
# ١) تثبيت الاعتماديات
composer install

# ٢) ملف البيئة
cp .env.example .env
php artisan key:generate

# ٣) قاعدة البيانات
#    الأسهل محليًا — SQLite: اضبط DB_CONNECTION=sqlite في .env
#    واحذف/علّق أسطر DB_HOST و DB_PORT و DB_DATABASE و DB_USERNAME و DB_PASSWORD
touch database/database.sqlite
php artisan migrate --seed

# ٤) التشغيل
php artisan serve
```

الرابط: <http://127.0.0.1:8000>

> **ملاحظة:** واجهات المشروع تستخدم `public/css/theme.css` مباشرة، فلا حاجة لـ`npm install`
> أو بناء Vite للتشغيل.

### حسابات الدخول التجريبية

الرابط: `‎/admin/login`

| الدور | البريد | كلمة المرور |
|---|---|---|
| مدير النظام | admin@manafi.sa | ChangeMe@2026 |
| استقبال | reception@manafi.sa | ChangeMe@2026 |
| مبيعات | sales@manafi.sa | ChangeMe@2026 |

⚠️ كلمات مرور تجريبية للتطوير فقط — **غيّرها فورًا في بيئة التشغيل الفعلي.**

كذلك يضيف الـseeder ٣ ضيوف تجريبيين و٦ مناطق عرض — **تُحذف قبل التشغيل الفعلي.**

## بنية المشروع

```
app/
  Enums/              أدوار المستخدمين وحالات الضيوف
  Http/Controllers/   Public / Auth / Admin (Dashboard, Guest, Checkin,
                      Message, Lead, Zone, User, Report, Permission)
  Support/            Qr (توليد الرموز) · Permissions (مرجع الصلاحيات)
  Models/             Guest, Zone, Lead, Message, Setting, User
database/
  migrations/         جداول الضيوف والمناطق والرسائل والإعدادات
  seeders/            المستخدمون + بيانات تجريبية
resources/views/
  public/             الواجهة العامة
  admin/              لوحة التحكم
  layouts/            قوالب RTL
public/
  css/theme.css       ثيم manafi.sa
  js/                 مكتبة قراءة QR بالكاميرا
```

إعدادات الحفل (الاسم/التاريخ/المكان) وبيانات التواصل في جدول `settings` —
تعديل التاريخ يغيّر العد التنازلي، وبيانات التواصل تظهر في صفحة «تواصل معنا»
عند تعبئتها فقط:

```bash
php artisan tinker --execute="
  App\Models\Setting::set('contact_phone', '+966 12 345 6789');
  App\Models\Setting::set('contact_whatsapp', '+966 50 123 4567');
  App\Models\Setting::set('contact_email', 'info@manafi.sa');"
```
